# Checklist: Adicionar Mapa

1. Criar cena em `Assets/aaPasta/Cenas`.
2. Criar assets em `Assets/aaPasta/Mapas/Nome`.
3. Configurar raiz visual do mapa.
4. Configurar NavMesh.
5. Configurar spawn points de jogadores.
6. Configurar rotas e spawn points de inimigos.
7. Configurar objetivo/base.
8. Configurar areas validas de torres e armadilhas.
9. Adicionar ao Build Settings somente quando estiver jogavel.
10. Testar singleplayer e MPPM.
11. Criar `docs/mapas/Nome.md`.
